# Applied Computing Studio 2 (FAC12492)

A permanent applied computing course for CORS Faculty.

## Lesson sequence

1. **Applied computing project planning**
   Break a practical computing project into milestones and technical risks.

2. **Integrate components and data**
   Connect components through documented interfaces and validated data flows.

3. **Evaluate and present project outcomes**
   Assess a solution against its goals and present evidence-based findings.

## Practice

Use the course practice assignment to explain the key ideas in your own words and support your answer with an example.
