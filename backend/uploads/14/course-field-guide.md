# Applied Predictive Models (AIM402)

Developing predictive models for practical data problems.

## Lesson sequence

1. **Feature preparation**
   Prepare features while preserving data meaning and avoiding target leakage.

2. **Regression and classification workflows**
   Select a predictive approach based on outcome type and decision need.

3. **Validation and error analysis**
   Use validation data and error slices to assess model reliability.

4. **Prediction deployment and monitoring**
   Track deployed prediction quality as data and usage change.

## Practice
