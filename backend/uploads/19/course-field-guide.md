# Database Systems Design (DBE401)

Relational design, integrity, and performance fundamentals.

## Lesson sequence

1. **Relational modeling and keys**
   Represent entities and relationships with well-defined keys.

2. **Normalization and integrity**
   Reduce update anomalies while preserving useful integrity rules.

3. **SQL queries and indexes**
   Write relational queries and use indexes to support common access patterns.

4. **Transactions and concurrency**
   Use transaction boundaries and isolation to protect data consistency.
