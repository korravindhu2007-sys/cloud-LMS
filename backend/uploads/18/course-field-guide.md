# Cloud Network Security (NET402)

Securing modern cloud-connected networks.

## Lesson sequence

1. **Cloud network boundaries**
   Map virtual networks, subnets, gateways, and service endpoints.

2. **Network identity and access**
   Apply identity-aware rules and least privilege to network access.

3. **Segmentation and traffic controls**
   Limit lateral movement with layered network segmentation.

4. **Cloud network monitoring**
   Use flow logs and alerts to investigate network exposure.
