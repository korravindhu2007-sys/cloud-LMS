# Cloud Architecture Basics (CLOUD-101)

Introductory cloud architecture concepts

## Lesson sequence

1. **Cloud architecture foundations**
   Identify the compute, network, storage, and identity layers in a cloud solution.

2. **Designing for availability**
   Use redundancy, health checks, and recovery planning to reduce service interruption.

3. **Scaling and capacity planning**
   Select vertical or horizontal scaling based on workload behavior.

4. **Cloud cost and governance**
   Use budgets, tagging, and least privilege to govern cloud resources.
