# Full Stack Applications (WEB402)

Developing integrated, production-minded web applications.

## Lesson sequence

1. **Full-stack application boundaries**
   Define contracts between the browser, server, and persistence layer.

2. **REST APIs and validation**
   Design predictable API resources and validate incoming data.

3. **Persistence and authentication**
   Connect data access and identity checks to application workflows.

4. **Deployment and observability**
   Prepare a full-stack application for deployment and diagnosis.
