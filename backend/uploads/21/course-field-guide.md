# Modern Web Engineering (WEB401)

Frontend and backend practices for modern web systems.

## Lesson sequence

1. **Modern web platform foundations**
   Understand the browser runtime, document structure, and rendering pipeline.

2. **Responsive and accessible interfaces**
   Build layouts that adapt to device sizes and accessible input.

3. **Web APIs and application state**
   Connect interface state to asynchronous API operations.

4. **Web performance and security**
   Reduce unnecessary work and apply secure browser-facing patterns.
