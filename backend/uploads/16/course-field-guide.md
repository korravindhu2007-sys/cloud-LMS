# Cross Platform UI Engineering (MOB402)

Creating maintainable interfaces across mobile platforms.

## Lesson sequence

1. **Cross-platform interface foundations**
   Share interface behavior while respecting platform conventions.

2. **Components and state**
   Structure reusable UI components and predictable application state.

3. **Native APIs and device capabilities**
   Integrate platform capabilities through stable abstractions.

4. **Cross-platform performance**
   Profile rendering and reduce unnecessary work on constrained devices.
