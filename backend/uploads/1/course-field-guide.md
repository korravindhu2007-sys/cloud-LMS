# Cloud Computing Fundamentals (CLOUD101)

Foundations of cloud computing and deployment patterns.

## Lesson sequence

1. **What is cloud computing?**
   Understand on-demand access to shared compute, storage, and networking resources.

2. **Cloud service models**
   Compare infrastructure, platform, and software services and the responsibilities each one leaves to the customer.

3. **Cloud deployment models**
   Distinguish public, private, hybrid, and community deployments by ownership and access.

4. **Infrastructure as a Service (IaaS)**
   Explore virtual machines, networking, and storage as configurable cloud infrastructure.

5. **Virtualization basics**
   Relate hypervisors and virtual machines to resource pooling and cloud elasticity.
